# pc-monitoring-system

## 💻 PC Monitoring System

Распределённая система мониторинга компьютерной техники для сбора, обработки, хранения и визуализации данных о состоянии компьютеров.

## 📌 О проекте

Проект предназначен для централизованного мониторинга компьютерной инфраструктуры. Система собирает информацию о загрузке процессора, использовании оперативной памяти, состоянии дисков и других системных показателях.

Для асинхронной передачи данных используется RabbitMQ, а для хранения информации — документная NoSQL-база данных MongoDB. Взаимодействие с данными осуществляется через API на FastAPI, а веб-интерфейс предоставляет возможность просматривать показатели и анализировать состояние компьютеров с помощью графиков.

## ⚙️ Технологический стек

-  Python — основной язык программирования.
-  psutil — сбор системных показателей.
-  RabbitMQ — брокер сообщений.
-  Pika — взаимодействие Python с RabbitMQ.
-  MongoDB — NoSQL-хранилище данных.
-  FastAPI — серверная часть и REST API.
-  HTML, CSS, JavaScript — веб-интерфейс.
-  Chart.js — визуализация данных.

🏗️ Архитектура системы

```text
💻 Агент мониторинга (Python + psutil)
                 |
                 v
              RabbitMQ
                 |
                 v
           Python Consumer
                 |
                 v
              CouchDB
                 |
                 v
              FastAPI
                 
                 v
          📊 Веб-интерфейс
```

## 🎯 Цель проекта

Разработка централизованной системы мониторинга компьютерной техники с использованием брокера сообщений и NoSQL-хранилища для асинхронного сбора, обработки, хранения и анализа системных показателей.

## ✨ Основные возможности

- 📊 Сбор характеристик и показателей производительности компьютеров.
- 📨 Асинхронная передача данных между компонентами системы.
- 🗄️ Хранение текущих и исторических данных в MongoDB.
- 📈 Визуализация показателей с помощью графиков.
- 🚨 Возможность выявления критических значений системных показателей.
